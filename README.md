### Convert words to simple music

This repository includes `word_to_music.py`, a small Python script that turns an
English word into a WAV file. Each letter is mapped to a musical note. Generate
a file with:

```bash
python word_to_music.py hello -o hello.wav
```

Copy the resulting WAV file to your mobile phone to practice the sound of the
word at any time.
